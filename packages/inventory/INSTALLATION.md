# Inventory Package Installation

The inventory package now follows the same internal structure as `fund-raise`:

- `src/apis`
- `src/apis/_shared`
- `src/pages`
- `src/services`
- `src/utils`
- `src/migrations`

This package is scaffolded for implementation in phases based on
`IMPLEMENTATION_SEQUENCE.md`.
